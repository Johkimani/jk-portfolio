## 🎯 Project Goal
The goal of this project is to create a modern, high-performance, and visually appealing personal portfolio website for **John Kimani**, a passionate software developer. This website serves as a central hub to showcase my background, technical skills, academic achievements, and real-world projects. It is designed to leave a strong first impression on recruiters, clients, and fellow developers through the use of premium aesthetics and interactive UI elements.

## 🚀 Technologies Used
This portfolio is built using core web technologies to ensure blazing-fast performance without the overhead of heavy frameworks:
- **HTML5**: Semantic markup for accessibility and SEO.
- **CSS3 (Vanilla)**: Custom styling using modern features like CSS Variables, Flexbox, Grid, CSS animations (keyframes), and Glassmorphism effects.
- **JavaScript (Vanilla)**: Lightweight DOM manipulation for interactive features (ScrollSpy navigation, Form handling).
- **Google Fonts**: Utilizing 'Poppins' and 'Inter' for clean, modern typography.
- **FormSubmit API**: For seamless, backend-less contact form email delivery.

## ✨ Features
- **Modern UI/UX Design**: A sleek color palette featuring Indigo & Slate, with soft shadows and hover micro-animations.
- **Dynamic Hero Section**: Features an eye-catching morphing gradient blob animation to grab user attention instantly.
- **Interactive Sticky Header**: A glassmorphic navigation bar that stays visible while scrolling.
- **ScrollSpy Navigation**: Navigation links automatically highlight based on which section of the page is currently in view.
- **Fully Responsive**: Optimized for seamless viewing across mobile, tablet, and desktop devices.
- **Functional Contact Form**: Integrated with FormSubmit for real-time email delivery, complete with a custom animated success message UI instead of basic browser alerts.
- **Project Showcase**: A dedicated grid layout detailing my work on platforms like the Tally App, Agricultural Website, and Calculator App.

## 💻 Installation & Local Setup

Since this is a static website built with pure HTML/CSS/JS, no complex backend setup or package installation is required!

### Steps to run locally:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Johkimani/jk-portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd jk-portfolio
   ```
3. **Run the project:**
   Simply open the `index.html` file in your preferred web browser. 
   - *Alternative (Live Server)*: If you are using VS Code, you can install the "Live Server" extension, right-click on `index.html`, and select "Open with Live Server" to view changes in real-time.

## 🛠️ How to Customize
- **Colors & Fonts**: Easily modify the global color scheme and typography by editing the CSS Variables (`:root`) at the very top of `styles.css`.
- **Contact Form**: The form is currently connected to FormSubmit.co. To receive emails, ensure the `action` attribute in `index.html` matches your email address. The first time you submit the form, you will receive an activation email from FormSubmit.
