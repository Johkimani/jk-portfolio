# Personal Portfolio 

Welcome to my personal portfolio website built entirely with HTML5 and CSS.

This project is designed to showcase my background, skills, projects, and contact information in a clean, responsive, and professional layout.

---

## 📌 Features

- ✅ Responsive layout using CSS media queries
- ✅ Profile image with animated transitions
- ✅ “About Me” section with smooth layout and hover effects
- ✅ Education section with downloadable CV
- ✅ Skills section styled with badge-like elements
- ✅ Project section using CSS grid
- ✅ Contact section with clickable email and social links
- ✅ Lightweight & fast (no JavaScript)

---

## 🛠️ How to Use

To view the site:

1. Clone or download the repository.
2. Place your image as `profile.jpg` and your CV as `cv.pdf` in the root folder.
3. Open `index.html` in any web browser.
