About Me

Hi, I’m John Kimani a passionate developer with a strong interest in solving real-world problems through code. My programming journey began when I saw how inefficient manual systems can be, especially in educational environments. I decided to learn how to build smarter, more reliable tools using technology.

I’m currently building a Tally App a digital attendance tracker for instructors that works offline and syncs data when connected. It’s being developed using HTML, CSS, JavaScript for the web version, and Kotlin for mobile. It’s a hands-on project that’s helping me improve my skills while directly impacting how people work.

I aim to become a full-stack developer who creates meaningful software for learning, community, and productivity. I also enjoy teaching others and exploring new technologies in my free time.
